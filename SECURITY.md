# Security

The tool executes document JavaScript in a separate browser process. It applies browser contexts, a restrictive content security policy, blocked external resource routing, a hard deadline and Windows Job Object cleanup. These controls limit ordinary runaway rendering; they are not a complete security boundary against deliberately malicious documents or browser vulnerabilities.

Convert trusted local files. Keep the bundled browser updated by using current releases or selecting an updated local Edge/Chrome. Do not put passwords, credentials or private environment data in figure scripts.

To report a vulnerability, use the repository's private vulnerability-reporting feature if available, or open an issue containing only a non-sensitive description and request a private channel. Do not publish credentials, private documents or a working exploit against another person's system.
