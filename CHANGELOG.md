# Changelog

## 0.3.1

- First public, MIT-licensed source export with synthetic fixtures and clean Git history.
- Windows x64 portable distribution with an optional bundled Chromium Headless Shell.
- Relative launch scripts, optional desktop/context-menu helpers, local runtime data and relocation checks.
- Privacy audits for source, portable archives, Python bytecode and commit metadata.
- Explicit distribution license collection for Python, Tcl and Python dependencies; incomplete license sets stop the build.
- Includes native drop queueing, isolated rendering, cancellation, HTML/SVG/Canvas/Mermaid, local layout components, correct SVG expressions, grid boundaries and bounded IPC read retries.

Earlier private development snapshots are intentionally not included in the public Git history or release downloads.
